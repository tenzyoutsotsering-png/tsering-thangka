# UX Writing Skill

Use this skill for navigation labels, buttons, forms, course information, booking flows, commission forms, and other interface copy for Tsering Thangka Studio.

## Principles
- Make every label immediately understandable on a phone.
- Prefer specific actions: Enquire About a Workshop, Request a Commission, View Course, Check Availability.
- Keep button labels short and action-led.
- Put important information before decorative language.
- Explain pricing, duration, participant limits, materials, payment, confirmation, and next steps plainly.
- Never hide important booking conditions behind poetic copy.

## Mobile
- Headlines should remain understandable when wrapped to 2-4 lines.
- Keep CTAs thumb-friendly and recognizable.
- Avoid long navigation labels.
- Use progressive disclosure for detailed course and commission information.
